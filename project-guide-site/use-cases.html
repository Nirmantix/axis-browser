Say what you need; BrowserBay picks the tool.

Each row is a use case the browser-bay router handles: the goal, a copy-pasteable operator prompt, and the tools the task routes to. Axis Browser commands carry an explicit CHROME_DEVTOOLS_AXI_MODE — managed for login state, ephemeral for fresh work — never an inherited ambient target.

Local app and page checks

Fast diagnostics and deterministic evidence on your own dev server or a public page you control.

Local UI check / screenshot

Confirm a local page renders and capture a screenshot artifact.

Say

"Use browser-bay to check my app: run CHROME_DEVTOOLS_AXI_MODE=ephemeral axis-browser open http://localhost:3000, snapshot it, and save a screenshot to .tmp/screenshots/home.png."

Routes to

Axis Browser → project-local Playwright → Browser Harness (isolated CDP target only) → agent-browser. Reference: references/screenshots.md.

Responsive screenshots

Capture the same page at phone, tablet, and desktop widths.

Say

"Use browser-bay to capture responsive screenshots of the landing page at 375, 768, and 1440 px into .tmp/screenshots/responsive/."

Routes to

Axis Browser or Playwright → Browser Harness (isolated target only) → agent-browser. Reference: references/screenshots.md.

Console / network root cause

Find the failing request or exception before editing code.

Say

"Use browser-bay to find why checkout fails: CHROME_DEVTOOLS_AXI_MODE=ephemeral axis-browser open http://localhost:3000/checkout, then console --type error --limit 25 --page 0 and network --type fetch --limit 25 --page 0 before touching code."

Routes to

Axis Browser (fastest bounded path) → Playwright listeners → Browser Harness (isolated target only). Bounded-diagnostic patterns reused from Tencent BrowserSkill (reference only — its extension/daemon is never installed). References: references/runtime-debugging.md, references/feature-debugging.md.

Accessibility review

Audit a page against WCAG rules with evidence.

Say

"Use browser-bay for an accessibility review of http://localhost:3000 — CHROME_DEVTOOLS_AXI_MODE=ephemeral axis-browser snapshot plus a lighthouse audit, report under .tmp/reports/."

Routes to

Axis Browser (snapshot + Lighthouse) → Playwright + axe-core → Browser Harness (isolated target only); Pa11y for CI-able sweeps. Reference: references/accessibility.md.

Performance / Lighthouse

Measure Core Web Vitals, traces, and heap on a real page.

Say

"Use browser-bay to measure the landing page: CHROME_DEVTOOLS_AXI_MODE=ephemeral axis-browser open http://localhost:3000, then lighthouse --output-dir .tmp/reports (lighthouse audits the open page — it takes no URL)."

Routes to

Axis Browser (lighthouse, perf-*, heap) → Playwright + Lighthouse CLI → Browser Harness (isolated target only). Reference: references/performance.md.

Reproducible E2E / CI

Turn a proven flow into a deterministic, rerunnable test.

Say

"Use browser-bay to turn the signup flow into a project-local playwright@1.63.0 test that runs in CI, with a trace on failure."

Routes to

Project-local Playwright → Axis Browser → Browser Harness (isolated target only). Reference: references/feature-testing.md.

Visual regression

Diff before/after renders of the same page.

Say

"Use browser-bay to visual-regression the settings page against the previous baseline, storing diffs under .tmp/."

Routes to

Playwright toHaveScreenshot → Axis + ImageMagick compare → Browser Harness (isolated target only) + compare. Reference: references/visual-regression.md.

Sessions, auth, and authorized targets

Login state and protected sites — the rows where the dedicated-target gate and authorization checks bite hardest.

Human handoff / live testing

A person may need to solve a captcha, MFA, or manual confirm mid-task.

Say

"Use browser-bay to drive the staging dashboard in ego lite and hand off to me if a captcha or MFA prompt appears."

Routes to

ego lite (the only human-handoff path; operator-approved accounts only) → else escalate with ! axis-browser login <url>. Reference: references/ego-browser.md.

Unattended auth flow test

Reproduce a login-dependent flow without a human in the loop.

Say

"Use browser-bay to test the signin flow unattended: hand me ! axis-browser login https://app.example.com once, then re-run CHROME_DEVTOOLS_AXI_MODE=managed axis-browser open and snapshot against the managed profile."

Routes to

Axis managed after one operator-run login → Playwright storageState → Browser Harness (isolated target only). Reference: references/auth-flow-testing.md.

Authorized protected-site work

Systems you own, administer, or hold written authorization to test.

Say

"Use browser-bay for authorized protected-site extraction on our admin portal (we administer it): run browser-act --session portal navigate https://portal.internal.example (stealth Chromium is its baseline; --session is required for interaction commands) and export the report under .tmp/scrapes/."

Routes to

BrowserAct (local stealth only — no chrome/chrome-direct ambient modes) → Firecrawl → Browser Harness (isolated target only); CloakBrowser when a Playwright-compatible stealth runtime is required. Reference: references/protected-sites-scraping.md.

Extraction and recurring jobs

Public-page markdown, JS-heavy extraction, named-extractor runs, and jobs that repeat.

Static public-page markdown

Clean article/docs text without browser overhead.

Say

"Use browser-bay to extract https://docs.example.com/guide as clean markdown into .tmp/scrapes/guide.md with Firecrawl."

Routes to

Firecrawl MCP/CLI (keyless-capable, quota-limited) → Playwright → Axis eval → BrowserAct (authorized targets only). Reference: references/content-scraping.md.

JS-heavy public extraction

Render a SPA before scraping its content.

Say

"Use browser-bay to scrape the JS-rendered docs SPA at https://app.example.com/docs — render with project-local Playwright, convert main content to markdown, save under .tmp/scrapes/."

Routes to

Project-local Playwright → Axis eval → Firecrawl interact. Reference: references/content-scraping.md.

High-volume extraction (named Obscura)

Bulk text/markdown/structured pulls where footprint or local speed matters.

Say

"Use browser-bay to run Obscura over these 200 docs URLs for title and body extraction into .tmp/scrapes/obscura/."

Routes to

Obscura — explicit trigger only (the operator must name it; never a default or fallback), pinned obscura-trial:79b16710 build, extraction-shaped steps only. Without the word: Firecrawl → Playwright/Axis. Reference: references/obscura.md.

Recurring extraction jobs

A pull that repeats — make it a reusable skill, script, or cloud function.

Say

"Use browser-bay to make this weekly authorized report pull repeatable — forge a BrowserAct Skill Forge skill if the site qualifies, else a reusable workflow script I can rerun."

Routes to

Authenticated recurring pulls → ego-browser learnings packs; authorized recurring extraction → BrowserAct Skill Forge → Notte Functions; rerunnable local runs → reusable-workflow script.mjs. References: references/ego-browser.md, references/protected-sites-scraping.md, references/notte-workflows.md, references/reusable-workflow.md.
