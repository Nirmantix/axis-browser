Commands and entry phrases.

Axis Browser diagnostics

Use these for compact state from a real browser.

Open and inspect

axis-browser open URL
axis-browser snapshot

Routes to

Axis Browser bridge and chrome-devtools-mcp.

Expected output

Page title, URL, accessibility snapshot, generation-tagged refs.

Runtime debugging

axis-browser console --type error
axis-browser network --type fetch

Routes to

DevTools console and network surfaces.

Expected output

Error list, request list, IDs for console-get and network-get.

Evidence capture

axis-browser screenshot .tmp/screenshots/page.png --full-page

Routes to

Current selected page in the Axis bridge.

Expected output

Screenshot artifact under .tmp/screenshots/.

Preflight

axis-browser doctor --json

Routes to

Mode resolution, endpoint probe, browser binary, profile lock, bridge and orphan state.

Expected output

Status, blockers, and a remedies array of syntactically runnable commands — not all safe unattended. Run the reversible ones (unset …); confirm the destructive ones (axis-browser reap, axis-browser stop, rm <path>). Escalate outright only for NEEDS_INTERACTIVE_LOGIN or PORT_HELD_BY_FOREIGN_PROCESS. Local CDP has no authentication — never request credentials or a ws:// URL.

One-time login

axis-browser login URL

Routes to

Headed browser on the managed profile; refuses without a TTY.

Expected output

Saved profile state; later runs are silent. Stops the bridge so the profile lock is released.

Orphan cleanup

axis-browser reap --dry-run
axis-browser reap

Routes to

Bridges carrying our own marker, claimed by no session, older than 4h.

Expected output

Orphan list with ages, and what was reaped. Also runs automatically on bridge start unless CHROME_DEVTOOLS_AXI_AUTO_REAP=0.

Setup and browser-bay routes

Use the CLI for public setup. Use browser-bay scripts only after a trusted local router is configured.

Project setup

axis-browser setup --install --project /path/to/project

Routes to

Read-only report by default; router setup only when install mode is approved.

Expected output

Readiness status, and project artifact setup when a local router is configured.

Tool check

axis-browser setup --json --project /path/to/project

Routes to

Machine-readable readiness report.

Expected output

Missing tools, auth presence signals, no installs, no secret values.

Resolve skill path
BB=""
c="${BROWSER_BAY_DIR:-${BROWSER_SKILL_DIR:-}}"
[ -n "$c" ] && [ -d "$c" ] && BB="$c"
for p in "${AXIS_BROWSER_HOME:+$AXIS_BROWSER_HOME/skills}" "${AXIS_PORTABLE_SKILLS_DIR:-}" \
         ./skills "$HOME/.codex/skills" "$HOME/.config/agents/skills" \
         "$HOME/.claude/skills" "$HOME/.config/opencode/skills" \
         "$HOME/.pi/agent/skills" "$HOME/.agents/skills" \
         "$HOME/.cursor/skills" "$HOME/.kiro/skills" "$HOME/.gemini/skills"; do
  [ -n "$BB" ] && break
  [ -n "$p" ] || continue
  for n in browser-bay browser-skill; do
    if [ -d "$p/$n" ]; then BB="$p/$n"; break; fi
  done
done
[ -d "$BB" ] || { echo "browser-bay not found; set BROWSER_BAY_DIR"; exit 2; }
Routes to

The same order axis-browser setup uses: BROWSER_BAY_DIR, $AXIS_BROWSER_HOME/skills/browser-bay, $AXIS_PORTABLE_SKILLS_DIR/browser-bay, ./skills/browser-bay, then standard agent skill locations.

Expected output

A resolved $BB, or exit 2 with browser-bay not found when no route matches.

Machine setup

axis-browser setup --install

Routes to

Permission-gated machine-level setup report and router delegation.

Expected output

Core and optional tool actions approved, skipped, or blocked. No credential writes.

Health audit

Resolve $BB with the chain in the “Resolve skill path” row above, then:

bash "$BB/scripts/check-prerequisites.sh" --update

Routes to

Report-first version-drift audit for shared tools.

Expected output

Current versions, update recommendations, and permission-gated follow-up actions.

Verified run

Resolve $BB with the chain in the “Resolve skill path” row above, then:

node "$BB/scripts/init-verified-run.mjs" --task "..." --slug run
node "$BB/scripts/validate-verified-run.mjs" --run .tmp/verified-runs/run

Routes to

Evidence-backed browser task workflow.

Expected output

Validated STEP markers with exit code 0, 1, or 2.

Target-project readiness.

Browser task launcher.

prompts/abuse.md and SKILL.md.

prompts/abhealth.md, router update audit when a router is configured, and read-only content consistency review.

Version audit, changelog impact, stale-doc findings, and proposed follow-up edits.
