Pick tools by job, not by novelty.

The Axis Browser workflow is tool-routed. Axis Browser is the compact diagnostic path, Browser Harness handles interactive browser work, and Playwright is added project-local for deterministic automation.

Core and common tools

Axis Browser

Fast shell-level diagnostics for browser and CDP workflows. v0.1.35 · Node 22.13+ · aliases axib / chrome-devtools-axi

GitHub
  • Use for snapshots, refs, console, network, Lighthouse, perf, and heap.
  • Default stdio mode spawns a pinned package-local chrome-devtools-mcp@1.9.0 with --redactNetworkHeaders — never a global install or npx …@latest. An explicit CHROME_DEVTOOLS_AXI_MCP_PATH override selects the build you point it at.
  • Does not own an LLM loop. Host agents compose commands.
Browser Harness

Optional high-capability interactive browser tool in browser-bay. installed checkout version via uv — inspect browser-harness --version

GitHub
  • Conditional — install it only for an explicit isolated CDP target (BU_CDP_URL/BU_CDP_WS on a purpose-launched, non-default-profile Chrome), never as a default route.
  • Use for visual control, iframes, odd widgets, and flexible browser operation.
  • Durable editable checkout; run check-prerequisites.sh --print-install-commands for the resolved clone path and install commands.
Playwright library

Deterministic browser automation library and test backend. playwright@1.63.0, installed project-local

Official docs
  • Use for repeatable scripts, traces, API mocking, CI, visual regression, and cross-browser checks.
  • Install project-local when the target project needs those capabilities.
Microsoft Playwright CLI

Agent-oriented Playwright CLI, separate from project-local Playwright. @playwright/cli@0.1.21 · Node 20+

Official docs
  • Use when its CLI command surface or installed skills are useful.
  • Optional. It overlaps with Axis Browser and agent-browser.

Node floors at a glance: Axis Browser 22.13+; standalone browser-bay and Playwright 20+; @playwright/cli 20+; firecrawl-mcp 22+; pa11y ^22.13 or 24+; agent-browser 24+.

Optional services and runtimes

Firecrawl CLI/MCP

Clean public-page markdown, crawl/search, structured extraction, and browser tools. firecrawl-cli@1.23.3 · firecrawl-mcp@3.24.0 (Node 22+)

Codex MCP docs CLI GitHub
  • Use when a browser is overkill for public content.
  • Keep API keys in user-local env or MCP config.
BrowserAct

Authorized protected-site workflows, screenshots, bulk extraction, and Skill Forge.

Skills GitHub Skill Forge
  • Use only on systems owned, administered, or explicitly authorized for testing.
  • A prebuilt site skill is not authorization.
Notte

Cloud browser sessions, live viewer, workflow-code export, Functions, vaults, and personas.

Website Docs
  • Use when production browser workflows or cloud replay matter.
  • Credentials stay in Notte or user-local config.
CloakBrowser

Playwright/Puppeteer-compatible Chromium runtime for authorized anti-detection tests.

Website GitHub
  • Use as a narrow runtime, not a default browser automation strategy.
  • It is not a CAPTCHA solver or hosted proxy service.
agent-browser

Optional fallback CLI with browser control, install flow, and skills. agent-browser@0.38.1 · Node 24+

Skills docs
  • Use when it is the quickest available native route.
  • Run agent-browser doctor when an install looks stale.
Webwright

Microsoft research harness above Playwright where an LLM writes and verifies scripts.

GitHub Project site
  • Do not add it as an Axis Browser dependency.
  • Borrow verified-run and reusable-script discipline through browser-bay.
ego lite

Authenticated interactive work reusing the operator's live logins. ego-browser skill · macOS only · no headless/CI

GitHub Docs
  • A browser, not a library: no CDP port, so no other tool can drive it.
  • Route to its skill — npx skills@1.5.18 add citrolabs/ego-lite — and never edit it; it is a symlink into the app bundle.
Pa11y

Accessibility checks via WCAG rules in CI-able runs. pa11y@10.0.0 · Node ^22.13 || >=24

Website
  • Use for automated accessibility sweeps; pair with manual screen-reader passes.
  • Skipped with an explicit note on Node 20, 21, or 23 — the engine refuses them.
Playwright MCP

Separately published MCP server exposing Playwright to MCP clients. @playwright/mcp · user-managed only

GitHub
  • Only when an MCP-capable client explicitly wants it; browser-bay never auto-installs it.
  • Not part of the playwright library install, and not the Axis Browser transport.
Browserbase skills

Separate Browserbase cloud/session ecosystem with its own CLI, API key, and platform workflows.

Skills GitHub Website
  • Use only when the task intentionally targets Browserbase cloud sessions or platform features.
  • Do not route normal Axis Browser work through Browserbase skills by default.

Utilities the workflow leans on

skills CLI

Installs and updates skills, including browser-bay. skills@1.5.18 · Node 18+ (registry engines)

npm
  • npx --yes skills@1.5.18 add <repo> is the reproducible form; bare skills@1.0.0 resolves to an unrelated package published 2016-10-06 (registry engines: >=18 applies to 1.5.18, not that one).
uv

Python tool installer used for the durable editable browser-harness checkout.

Docs
  • Install from the harness checkout with uv tool install -e .; add --force only when refreshing an already-installed tool.
ImageMagick compare

Pixel-diff engine behind visual-regression and cross-browser screenshot checks.

Docs
  • compare -metric AE produces the diff counts the references build on.
jq and pandoc

Structured JSON inspection and document conversion in content workflows.

jq pandoc
  • Skill scripts deliberately avoid depending on jq so bare-shelf machines still run.
Python 3

Stdlib-only scripts, including this microsite's validator. python3 · no pip packages

  • validate_static_site.py gates every PR through the microsite CI job.
ShellCheck and git

Lint for the skill's shell scripts; git for the harness and skill checkouts.

ShellCheck
  • browser-bay CI runs its test suite on Node 20 and 24; ShellCheck itself is a manual contributor step, and the scripts are held clean at that bar.

Fast picker

Task Use Why
Debug a local UI fast Axis Browser or Browser Harness Lowest overhead and direct browser state.
Write CI-grade automation Project-local Playwright Deterministic waits, traces, network interception, cross-browser.
Extract public documentation Firecrawl Clean content without browser overhead.
Work on protected targets BrowserAct, Notte, or CloakBrowser Only with explicit authorization and credential hygiene.
Use Browserbase cloud sessions Browserbase skills Separate ecosystem; only when Browserbase infrastructure is explicitly required.
Accessibility sweep Pa11y WCAG rules in CI-able runs; needs Node ^22.13 or 24+.
Install or update a skill skills CLI Reproducible installs at skills@1.5.18, including browser-bay itself.
Need reusable proof browser-bay verified run or craft workflow Structured evidence, STEP markers, and rerunnable scripts.
